
# Phaglp Platform Live

> **Important:**  
> The main application is located in the `phaglp-platform28012026-master` directory. All development, builds, and deployments (via Vercel) use this folder as the root.

## Development Setup

1. Clone the repository.
2. Work in the `phaglp-platform28012026-master` folder for all application source code.
3. To run locally:
   ```bash
   cd phaglp-platform28012026-master
   npm install
   npm run dev
   ```

## Deployment

This repository is configured to deploy from the `phaglp-platform28012026-master` directory on [Vercel](https://vercel.com/).
